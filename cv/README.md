# Shijie Liu CV

This directory contains the Awesome-CV LaTeX source for `data/ShijieLiu-CV.pdf`.

The template class is copied from:

https://github.com/posquit0/Awesome-CV

## Build on Windows

Open PowerShell in this directory and run:

```powershell
.\build-windows.ps1
```

Or in Command Prompt:

```bat
build-windows.bat
```

The script runs `xelatex` twice and copies the generated PDF to:

```text
..\data\ShijieLiu-CV.pdf
```

That is the file linked from the website homepage.
