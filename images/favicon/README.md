# Personal avatar and search icon

`jason-avatar.png` was generated with the built-in image generation tool using
`../ShijieLiu.jpg` as the identity reference. The numbered PNG files and root
`favicon.ico` are resized exports for browsers, Google Search, and Apple devices.
Keep the published favicon URLs stable so crawlers can refresh them.

## Generation prompt

Use case: style-transfer. Asset type: square cartoon portrait favicon for Jason Shijie Liu's academic website. Reference image: the provided portrait is the identity reference. Create one clean friendly cartoon head-and-shoulders avatar recognizable as this person: preserve short black hairstyle, face shape, eyebrows, clean-shaven face and dark suit with white shirt. Large centered face occupying most of the square, simplified bold shapes and crisp outlines readable at 32px, softly rounded illustration style, gentle natural smile. Light blue plain background inspired by the reference. Keep all hair and face safely within a circular crop, minimal shoulder area. No text, letters, logo, frame, watermark or extra objects. Output a single square PNG.

`favicon.svg` retains the previous icon URL, with the same avatar embedded as PNG,
so clients revisiting that URL no longer receive the old initials. The homepage
continues to advertise the raster PNG and ICO files for search engines.
